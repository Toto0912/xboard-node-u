# 二次开发功能说明

xboard-node-u 基于原版 Xboard-Node，支持机器模式、面板单节点模式和无面板独立运行。本页介绍二次开发功能；安装和管理命令见 [README](../README.md)，具体内核版本及发布状态见 README 顶部和 [变更记录](../CHANGELOG.md)。

## 双内核更新与兼容

更新嵌入式 sing-box 和 Xray-core，并迁移 Xboard 用户热更新、限速、流量统计及协议兼容补丁。两套内核随节点程序提供，无需单独安装；可按实例选择内核。

机器模式按对应节点的实际内核处理配置；Xray 配置重载保留启动失败回滚和累计流量统计。已有面板通信接口继续使用，包含用户同步、配置拉取、WebSocket 推送及流量上报。

## 面板节点 Fallback

配合包含此功能的 [xboard-u](https://github.com/Toto0912/Xboard-u)，在面板编辑 VLESS / Trojan 节点，选择 TCP/RAW 和 TLS / Reality 后，填写安全性设置下方的可选 `Fallback`。机器模式和单节点模式均支持 REST 拉取与 WebSocket 更新，节点端无需在 `config.yml` 重复填写。

目标格式为 `域名:端口`、`IP:端口` 或 `[IPv6]:端口`。面板将有效输入保存并下发；空值、格式错误或不适用当前协议组合的配置按空值处理。

| 节点内核与安全性 | 处理方式 | 目标示例 |
| --- | --- | --- |
| Xray + TLS | 协议层普通回落，连接 TLS 解密后的明文后端，默认 HTTP/1.1 | `127.0.0.1:8080` |
| Xray + Reality | 覆盖 Reality HTTPS 伪装目标，实现“Reality 偷自己” | `127.0.0.1:8443` |
| sing-box | 忽略回落配置，保持原来的节点行为 | 无需为此修改节点端配置 |

### TLS 普通回落

目标通常是本机明文 HTTP 网站。浏览器访问节点 HTTPS 端口时，非代理请求进入该网站，合法代理连接继续正常使用。普通 TLS 回落与 VLESS 额外加密不兼容，面板会禁用输入并提示，保存时清空不兼容配置。

### Reality“偷自己”

例如 Xray 监听 `443`，本机 Nginx HTTPS 网站监听 `127.0.0.1:8443`，在面板 Fallback 中填写 `127.0.0.1:8443`。节点端将其设置为 Reality 目标，保留原 SNI、密钥和 Short ID；目标须支持 TLS 1.3，证书匹配原 SNI。

普通浏览器连接由 Reality 转发至目标网站，合法 Reality 代理连接照常使用。这是 Reality 的目标站转发，不会额外添加普通 TLS 的明文回落规则。

### 兼容与限制

- 面板和节点端均须包含此功能；旧面板、留空或无效输入沿用原有节点行为。
- sing-box 会丢弃面板回落字段，该字段单独变化不触发多余的配置重载。
- 回落属于服务端设置，面板不会将其写入 sing-box、Clash 等客户端订阅，客户端连接参数保持原样。
- 回落目标不能指向代理自身监听端口。

## 无面板独立运行与原生回落

通过本地 `standalone` 配置读取节点和用户，无需面板地址、机器 ID 或通信密钥，也不向面板上报数据；可与机器模式放在同一个多实例配置中运行。

独立模式的 `standalone.node.fallbacks` 支持 Xray VLESS / Trojan TCP/RAW + 普通 TLS 的默认、SNI、ALPN、HTTP 路径回落，以及 PROXY protocol。它与面板下发的单一 Fallback 目标分开处理，不用于 sing-box、HY2、Reality 或 VLESS 额外加密组合；不兼容或无效的原生回落配置会在加载时明确报错。

独立模式的 Reality 伪装目标继续在 `standalone.node.tls_settings.dest` 中配置。

- [独立运行指南](STANDALONE.md)：完整配置、客户端参数及与机器模式共存方式。
- [VLESS + TLS 回落示例](../examples/standalone-vless-fallback.yml.example)：证书、本地网站及原生回落列表写法。

## 安装与统一管理

提供 Linux systemd 和 Alpine Linux / OpenRC 两种独立安装脚本，均使用 `xbctl` 进行状态查询、启停、日志、实例绑定、升级及卸载管理。Alpine LXC 无需安装 systemd。

安装器及管理工具使用本项目正式发布资源，保留已有配置与凭据，并提供升级校验及失败回滚。具体一键命令和常用管理命令见 [README](../README.md)。
