# 二次开发功能说明

xboard-node-u 基于原版 Xboard-Node，支持机器模式、面板单节点模式和无面板独立运行。本页介绍二次开发功能；安装和管理命令见 [README](../README.md)，具体内核版本及发布状态见 README 顶部和 [变更记录](../CHANGELOG.md)。

以下按版本从新到旧整理，各版本内按功能说明详细改动。历史行为发生变化时，以较新版本的说明为准。

## v2.2.1

### Xray 内核升级

同步官方 [Xray-core v26.11.9](https://github.com/XTLS/Xray-core/releases/tag/v26.11.9)，固定提交 `676eaf66f8f05d4d558ee7a74b4736623d3feeb9`。保留本项目的限速、流量统计、在线设备、用户热更新、MUX 和 HY2 兼容补丁，并同步新版要求的 uTLS / Reality / gRPC 等依赖。

机器模式、面板单节点模式、无面板独立运行沿用现有配置与通信接口。原版 Xboard 及旧版面板缺少可选扩展字段时仍使用原有默认处理。Sing-box 核心版本保持 1.14.4；共享依赖随 Go 模块选择结果更新，两个内核均须通过回归测试。

内核源码准备改用 `scripts/prepare-xray/` 中的固定提交及 `patches/xray-core-26.11.9.patch`。脚本会拒绝覆盖旧提交或包含手工改动的生成目录；从源码构建时，请保留自己的改动，并在干净构建目录执行 `make prepare`。补丁来源和许可证见 [第三方组件记录](../THIRD_PARTY_NOTICES.md)。

本功能随节点端 v2.2.1 发布，兼容配套面板 xboard-u v2.2.0；使用 `xbctl upgrade` 更新，当前发布状态见 [变更记录](../CHANGELOG.md)。

### 服务端本地自定义内核配置

本版补充既有 `kernel.custom_config` 功能的文档入口和完整用法，不改变配置行为。

在主配置文件的 `kernel.custom_config` 中指定本地 JSON 或 YAML 文件，可补充 DNS、自定义出站和路由等高级内核配置。机器模式、面板单节点模式及无面板独立运行均支持；多个使用相同内核的实例可共享文件，也可按实例分别设置。

该入口在节点服务器配置，不经面板下发，也不进入客户端订阅。Sing-box 与 Xray 使用各自的原生字段，不做跨内核翻译；配置按字段替换、追加或合并，不能用它覆盖自动生成的入站、用户及统计管理。`config_dir` 是工作目录，`custom_config` 才是自定义文件入口。

完整说明、三种运行模式示例、DNS 主备及合并边界见 [自定义内核配置指南](CUSTOM-CONFIG.md)。

## v2.2.0

### HY2 增强

修复 HY2 带宽及方向处理，新增自动 BBR / Brutal 协商和按内核生成的 Masquerade 示例，QUIC 性能参数继续使用内核默认值。兼容性、升级影响及具体写法见 [HY2 配置说明](HYSTERIA2.md)。

Sing-box 补齐 HY2 正值带宽映射，两套内核均可接收并应用面板下发的 Masquerade，覆盖机器模式、面板单节点模式及独立运行。面板带宽按客户端视角保存，下发服务端时交换上下行；客户端订阅保持原方向。

带宽留空时按新标记使用 BBR，填写正值时允许按客户端与服务端的较小限制协商 Brutal；旧版或原版面板缺少新标记时保留原协商默认行为。已填写的正值带宽在升级后会开始生效，需核对原配置。

修正 Xray HY2 的十进制带宽、BBR 握手提示、单方向无限制协商及 Salamander / Gecko 映射；修复 Sing-box 字符串伪装指定状态码时丢失响应头的问题。

## v2.1.0

### 稳定性与设备同步

修复 Xray 并发连接统计和准入共享状态访问，停止实例时同步释放监听端口。设备上报使用独立完整快照，持续在线也定期刷新，最后断开明确上报空快照；删除失效的设备去重、缓冲和恢复代码。

机器模式保留配置中空列表的原有形式，避免 WebSocket 重连时将相同配置误判为变化并重启内核。机器模式、单节点和独立模式无需增加配置，内核版本不变，既有面板通信接口保持不变。面板侧的完整设备状态处理与性能优化需配合 xboard-u v2.1.0。

### Reality 目标地址修正

同版本后续修正 Xray Reality 目标地址的组合：面板分开填写的 `dest` 和 `server_port` 会组合为完整目标；空目标回退到 SNI，已包含端口的目标保持优先。保留 SNI 和原生协议层 Fallback，适用于机器、单节点及独立模式。

## v2.0.0

### CDN 分离与传输参数兼容

配套 xboard-u 的 CDN 套用功能，继续使用既有节点通信结构。客户端与服务端的配置分离由面板完成，节点端应用面板下发的服务端参数，机器、单节点及无面板独立三种运行模式均保留。

补齐 Sing-box 的 gRPC 超时、HTTP 和 HTTPUpgrade 参数映射；Xray 将旧 WebSocket `headers.Host` 映射为独立 `host`，并对已移除的旧 HTTP/H2/H3 和 V2Ray QUIC 传输给出明确错误。增加本地 TLS 反代 XHTTP、Reality 与协议层回落下行的流量验证。

两端版本统一为 v2.0.0。本版内核仍为 sing-box 1.14.4 与 Xray-core 26.10.31。

### Sing-box 多实例 DNS 修正

同版本后续修复多实例共存时，一个实例重建关闭共享 D-Bus 连接，导致其他实例 DNS 解析失败的问题。重启或重建单个实例不应中断其他实例的本地 DNS 解析。

## v1.1.3

### 原生自定义出站与路由

面板和节点端同步升级到 v1.1.3 后，在节点高级设置中可直接填写 Sing-box 原生出站数组（type + 平铺参数），或 Xray 原生出站数组（protocol + settings 及其他原生顶层参数）。旧 protocol/settings/proxy_tag 写法继续支持，已有数据无需迁移；Sing-box 的旧 proxy_tag 转换为 detour。

原生参数不做跨内核翻译：节点端按实际内核校验，明确拒绝错用格式、未知出站引用及依赖循环；完整参数由已嵌入的实际内核解析。面板保留原生字段与空对象，不把未知字段静默删除，也不会将服务端出站和路由加入客户端订阅。

面板目前不保存每台运行实例的最终内核，保存时检查 JSON 结构，最终内核匹配与全部出站标签引用检查由节点端负责。先更新节点端，再在面板保存原生配置；旧节点端无法识别 Sing-box 原生 type 格式。

详细配置：[自定义出站](../docs-custom-outbounds.md)、[自定义路由](../docs-custom-routes.md)。

## v1.1.2

### 面板节点 Fallback

配合包含此功能的 [xboard-u](https://github.com/Toto0912/Xboard-u)，在面板编辑 VLESS / Trojan 节点，选择 TCP/RAW 和 TLS / Reality 后，填写安全性设置下方的可选 `Fallback`。机器模式和单节点模式均支持 REST 拉取与 WebSocket 更新，节点端无需在 `config.yml` 重复填写。

目标格式为 `域名:端口`、`IP:端口` 或 `[IPv6]:端口`。面板将有效输入保存并下发；空值、格式错误或不适用当前协议组合的配置按空值处理。

从 **v1.1.2** 起，面板回落与独立模式均采用 Xray 原生协议层语义：

| 内核与安全性 | 回落处理 |
| --- | --- |
| Xray + TLS | 生成协议层 `fallbacks`，连接解密后的明文后端，默认 HTTP/1.1 |
| Xray + Reality | 生成协议层 `fallbacks`，**保留原 Reality dest、SNI、私钥、Short ID 和 Flow** |
| sing-box | 忽略面板下发的回落字段，保持原有节点行为 |

Reality 鉴权失败或普通浏览器访问仍由 Reality 转发到原 HTTPS 目标；只有已通过 Reality 握手、但 VLESS / Trojan 协议首包或认证失败的连接才进入协议层回落。合法代理连接正常使用。TLS、Reality 的协议层回落都不能与 VLESS 额外加密组合。

面板继续使用可选单目标输入框；机器模式、单节点模式的 REST 与 WebSocket 更新均转换为一条原生回落。该字段只供服务端使用，不进入 sing-box、Clash 等客户端订阅。sing-box 忽略字段单独变化，避免多余重载。

### 无面板独立运行与原生回落

通过主配置文件的 `standalone:` 读取节点和用户，不需要面板。TLS 与 Reality 统一在该独立节点的 **`node:` 内添加 `fallbacks:` 列表**，与 `tls_settings:` 同级；无需另建文件，不增加 `xray_fallback` 独立字段。

支持 Xray VLESS / Trojan TCP/RAW 的默认、SNI、路径及 PROXY protocol 回落；ALPN 条件按内核实际协商值匹配。Reality 的原 `tls_settings.dest` 不变，当前内核 Reality 的 ALPN 通常为空，建议保留默认规则。不支持 sing-box、HY2、VLESS 额外加密或其他传输组合，无效配置会明确报错。

- [独立运行指南](STANDALONE.md)：完整结构、两层回落的区别及与机器模式共存方式。
- [Xray Reality 原生回落示例](../examples/standalone-xray-reality-fallback.yml.example)。
- [VLESS + TLS 回落示例](../examples/standalone-vless-fallback.yml.example)。

#### 从旧语义升级

面板与节点端应一并升级到 v1.1.2。旧面板 Reality Fallback 曾覆盖 HTTPS 目标，新版改为协议层回落，不再覆盖目标；升级前核对 Reality 原目标与回落后端端口，数据不会自动清空。需要“Reality 偷自己”时，在 Reality 目标设置中指定自己的 HTTPS 网站。

## v1.1.0

### 新增 Xray Fallback 回落

无面板独立模式新增 `standalone.node.fallbacks` 列表，初版支持 Xray VLESS / Trojan TCP + TLS 的默认、SNI、ALPN、路径回落及 PROXY protocol。对不兼容的内核、协议、传输、额外加密和无效回落参数给出明确错误，并提供 VLESS + TLS 完整配置示例。

支持 xboard-u 下发的可选 `xray_fallback`，覆盖机器模式、单节点模式的 REST 拉取与 WebSocket 更新。sing-box 忽略面板回落字段，不因该字段单独变化而多余重载；旧面板、空值及无效输入保持原行为。

本版初期将面板 Reality Fallback 用于覆盖伪装目标，独立模式初期仅开放普通 TLS 回落。[v1.1.2](#v112) 已统一为 Xray 原生协议层回落，并让 TLS / Reality 共用 `fallbacks` 列表；当前配置与升级注意事项请以 v1.1.2 一节为准。

## v1.0.2

### Xray-core 紧急安全更新

同步官方 Xray-core v26.10.31 安全更新，固定提交 `a4a3dff5b20c2faae567b742c172c7b95e75c083`。默认关闭 Xray TCP 监听与节点健康检查监听的 MPTCP，避免受 Go 隐式默认值或 `GODEBUG` 设置影响。

将原有 Xboard 限速、Mux、配置注册及 Hysteria 并发兼容补丁迁移至新固定版本，更新 protobuf 至 v1.36.12。三种部署模式继续使用现有配置，补充 Linux socket 协议、真实连接及 OpenRC 安装升级验证。

## v1.0.1

### Alpine Linux / OpenRC 安装与统一管理

提供 Linux systemd 和 Alpine Linux / OpenRC 两种独立安装脚本，均使用 `xbctl` 进行状态查询、启停、日志、实例绑定、升级及卸载管理。Alpine LXC 无需安装 systemd。

安装器及管理工具使用本项目正式发布资源，保留已有配置与凭据，并提供升级校验及失败回滚。具体一键命令和常用管理命令见 [README](../README.md)。

新增的 `install-alpine.sh` 与 systemd 安装器独立提供，不合并脚本；两者统一使用 `xbctl`。Alpine 安装及升级校验同版本的节点程序和管理工具，保存安装器，支持失败回滚和旧管理工具迁移。正式 Release 增加 Alpine 安装器附件及对应 SHA256 校验项。

兼容旧看门狗卸载后的残留文件，不依据过期 PID 文件误杀其他进程，保留原配置、凭据及其他启动任务；修复 `xbctl` 重写绑定时丢失旧配置内嵌令牌的问题。

## v1.0.0

### 双内核整合与三种运行模式

更新嵌入式 sing-box 和 Xray-core，并迁移 Xboard 用户热更新、限速、流量统计及协议兼容补丁。两套内核随节点程序提供，无需单独安装；可按实例选择内核。

机器模式按对应节点的实际内核处理配置；Xray 配置重载保留启动失败回滚和累计流量统计。已有面板通信接口继续使用，包含用户同步、配置拉取、WebSocket 推送及流量上报。

首个整合版本采用 sing-box 1.14.4 与 Xray-core 26.10.29，提供固定提交、完整补丁及重建脚本，统一 Go 1.27 构建配置。支持机器模式、单节点接入面板及无面板裸核运行，并可在同一主配置中管理多个实例。后续内核更新见较新版本章节。

### 用户更新、统计与生命周期兼容

迁移 Sing-box 用户热更新、Mieru 生命周期、HTTP / SOCKS / Naive 认证替换及配置重载；迁移 Xray 用户限速、Mux 包装读取器、SS2022 账户、Hysteria2 配置及用户更新。移除节点端对 Xray 配置工厂注册表的 unsafe / go:linkname 访问。

修复机器 WebSocket 事件使用全局内核解析配置的问题，改用对应节点已解析的内核；修复 Xray 同端口重载，保留启动失败回滚和累计流量。补充双内核真实协议连接、用户增删、流量统计、重载及并发检查，并修正 VMess / TUIC 用户表和 Xray Hysteria 会话关闭状态的竞争。

### 安装与发布

安装器和 `xbctl` 使用本项目发布仓库，GitHub 工作流按当前仓库生成 Release 与镜像地址。提供一行命令启动的交互安装向导，可选择机器 / 单节点和内核，密钥隐藏输入；多架构 Docker 构建采用本机交叉编译。
