# 二次开发功能说明

## HY2 增强（v2.2.0）

修复 HY2 带宽及方向处理，新增自动 BBR / Brutal 协商和按内核生成的 Masquerade 示例，QUIC 性能参数继续使用内核默认值。兼容性、升级影响及具体写法见 [HY2 配置说明](HYSTERIA2.md)。

xboard-node-u 基于原版 Xboard-Node，支持机器模式、面板单节点模式和无面板独立运行。本页介绍二次开发功能；安装和管理命令见 [README](../README.md)，具体内核版本及发布状态见 README 顶部和 [变更记录](../CHANGELOG.md)。

## 服务端本地自定义内核配置

在主配置文件的 `kernel.custom_config` 中指定本地 JSON 或 YAML 文件，可补充 DNS、自定义出站和路由等高级内核配置。机器模式、面板单节点模式及无面板独立运行均支持；多个使用相同内核的实例可共享文件，也可按实例分别设置。

该入口在节点服务器配置，不经面板下发，也不进入客户端订阅。Sing-box 与 Xray 使用各自的原生字段，不做跨内核翻译；配置按字段替换、追加或合并，不能用它覆盖自动生成的入站、用户及统计管理。`config_dir` 是工作目录，`custom_config` 才是自定义文件入口。

完整说明、三种运行模式示例、DNS 主备及合并边界见 [自定义内核配置指南](CUSTOM-CONFIG.md)。

## 稳定性与设备同步（v2.1.0）

修复 Xray 并发连接统计和准入共享状态访问，停止实例时同步释放监听端口。设备上报使用独立完整快照，持续在线也定期刷新，最后断开明确上报空快照；删除失效的设备去重、缓冲和恢复代码。

机器模式保留配置中空列表的原有形式，避免 WebSocket 重连时将相同配置误判为变化并重启内核。机器模式、单节点和独立模式无需增加配置，内核版本不变，既有面板通信接口保持不变。面板侧的完整设备状态处理与性能优化需配合 xboard-u v2.1.0。

## 双内核更新与兼容

更新嵌入式 sing-box 和 Xray-core，并迁移 Xboard 用户热更新、限速、流量统计及协议兼容补丁。两套内核随节点程序提供，无需单独安装；可按实例选择内核。

机器模式按对应节点的实际内核处理配置；Xray 配置重载保留启动失败回滚和累计流量统计。已有面板通信接口继续使用，包含用户同步、配置拉取、WebSocket 推送及流量上报。

## 面板节点 Fallback

配合包含此功能的 [xboard-u](https://github.com/Toto0912/Xboard-u)，在面板编辑 VLESS / Trojan 节点，选择 TCP/RAW 和 TLS / Reality 后，填写安全性设置下方的可选 `Fallback`。机器模式和单节点模式均支持 REST 拉取与 WebSocket 更新，节点端无需在 `config.yml` 重复填写。

目标格式为 `域名:端口`、`IP:端口` 或 `[IPv6]:端口`。面板将有效输入保存并下发；空值、格式错误或不适用当前协议组合的配置按空值处理。

从 **v1.1.2** 起，面板回落与独立模式均采用 Xray 原生协议层语义：

| 内核与安全性 | 回落处理 |
| --- | --- |
| Xray + TLS | 生成协议层 `fallbacks`，连接解密后的明文后端，默认 HTTP/1.1 |
| Xray + Reality | 生成协议层 `fallbacks`，**保留原 Reality dest、SNI、私钥、Short ID 和 Flow** |
| sing-box | 忽略面板下发的回落字段，保持原有节点行为 |

Reality 鉴权失败或普通浏览器访问仍由 Reality 转发到原 HTTPS 目标；只有已通过 Reality 握手、但 VLESS / Trojan 协议首包或认证失败的连接才进入协议层回落。合法代理连接正常使用。TLS、Reality 的协议层回落都不能与 VLESS 额外加密组合。

面板继续使用可选单目标输入框；机器模式、单节点模式的 REST 与 WebSocket 更新均转换为一条原生回落。该字段只供服务端使用，不进入 sing-box、Clash 等客户端订阅。sing-box 忽略字段单独变化，避免多余重载。

## 无面板独立运行与原生回落

通过主配置文件的 `standalone:` 读取节点和用户，不需要面板。TLS 与 Reality 统一在该独立节点的 **`node:` 内添加 `fallbacks:` 列表**，与 `tls_settings:` 同级；无需另建文件，不增加 `xray_fallback` 独立字段。

支持 Xray VLESS / Trojan TCP/RAW 的默认、SNI、路径及 PROXY protocol 回落；ALPN 条件按内核实际协商值匹配。Reality 的原 `tls_settings.dest` 不变，当前内核 Reality 的 ALPN 通常为空，建议保留默认规则。不支持 sing-box、HY2、VLESS 额外加密或其他传输组合，无效配置会明确报错。

- [独立运行指南](STANDALONE.md)：完整结构、两层回落的区别及与机器模式共存方式。
- [Xray Reality 原生回落示例](../examples/standalone-xray-reality-fallback.yml.example)。
- [VLESS + TLS 回落示例](../examples/standalone-vless-fallback.yml.example)。

### 从旧语义升级

面板与节点端应一并升级到 v1.1.2。旧面板 Reality Fallback 曾覆盖 HTTPS 目标，新版改为协议层回落，不再覆盖目标；升级前核对 Reality 原目标与回落后端端口，数据不会自动清空。需要“Reality 偷自己”时，在 Reality 目标设置中指定自己的 HTTPS 网站。

## 安装与统一管理

提供 Linux systemd 和 Alpine Linux / OpenRC 两种独立安装脚本，均使用 `xbctl` 进行状态查询、启停、日志、实例绑定、升级及卸载管理。Alpine LXC 无需安装 systemd。

安装器及管理工具使用本项目正式发布资源，保留已有配置与凭据，并提供升级校验及失败回滚。具体一键命令和常用管理命令见 [README](../README.md)。


## 原生自定义出站与路由（v1.1.3）

面板和节点端同步升级到 v1.1.3 后，在节点高级设置中可直接填写 Sing-box 原生出站数组（type + 平铺参数），或 Xray 原生出站数组（protocol + settings 及其他原生顶层参数）。旧 protocol/settings/proxy_tag 写法继续支持，已有数据无需迁移；Sing-box 的旧 proxy_tag 转换为 detour。

原生参数不做跨内核翻译：节点端按实际内核校验，明确拒绝错用格式、未知出站引用及依赖循环；完整参数由已嵌入的实际内核解析。面板保留原生字段与空对象，不把未知字段静默删除，也不会将服务端出站和路由加入客户端订阅。

面板目前不保存每台运行实例的最终内核，保存时检查 JSON 结构，最终内核匹配与全部出站标签引用检查由节点端负责。先更新节点端，再在面板保存原生配置；旧节点端无法识别 Sing-box 原生 type 格式。

详细配置：[自定义出站](../docs-custom-outbounds.md)、[自定义路由](../docs-custom-routes.md)。
