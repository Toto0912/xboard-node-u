# v2.4 - lastest 二次开发功能说明

## v2.4.1

### 流量重试和速率

节点与支持批次上报的面板握手后，将每批用户的上下行流量和唯一批次号写入本地。请求超时或回执丢失时重发同一批次，面板按节点和批次去重。收到匹配回执后，节点删除该批文件。旧面板继续使用原有上报协议。

默认批次目录位于节点的内核配置目录下，也可用 `XBOARD_NODE_TRAFFIC_DIR` 指定。容器部署请持久化该目录。每个节点最多保留 128 个待发批次，目录已满时，新采集的流量先在进程内累计。恢复期间请保留目录、面板 URL 和节点 ID，以便节点找到未确认批次。

速率统计采用实际经过的采样时间，使用自定义 `track_interval` 时也能按秒显示。Xray VLESS TCP 会分别对上下行应用用户带宽限制。

### 用户撤权与面板失联

WebSocket 和 REST 同时下发变更时，节点会识别拉取期间已更新的名单。重连后主动拉取完整名单，移除最后一名用户会停止内核，之后新增有效用户会重新启动。重建失败时，撤销的凭据也会从后续回滚使用的名单中移除。

运行中的节点在面板网络故障时继续使用最近生效的配置和名单，已有用户可维持连接或重新连接。期间新增用户、到期和封禁会延迟到恢复同步后生效。面板单节点和机器模式要从面板获取启动数据，故障期间应让正在工作的节点保持运行。机器发现接口明确返回 401、403 或空节点列表时，节点会执行撤权。

### 机器模式切换 XHTTP 与多 Xray 实例

运行中的 sing-box 子节点收到需要 Xray 的 XHTTP 配置时，机器主进程重新向面板确认配置和用户名单，校验后只停止并替换该子节点。该子节点上的客户端需要重连，同机器的其他节点继续运行。WebSocket 推送和定期轮询均可触发切换。

同一进程的多个 Xray 实例分别使用各自的 DNS 和出站配置，支持多个子节点使用相同的出站标签。内核版本为 sing-box 1.14.4 和 Xray-core 26.11.9。

### 证书更新与多节点目录

ACME 续签会通知服务重载，应用失败后继续重试。面板覆盖证书切换失败时恢复原配置及其证书；撤销覆盖后恢复节点的本地证书配置。

静态多节点将默认配置和证书目录按节点分开。升级时会检查旧目录中符合域名的自签证书和 ACME 站点证书，匹配后迁入新目录，以保留既有证书。手动指定目录时，应为各节点使用独立的证书目录。
