# xboard-node-u v2.2.0

HY2 带宽与 Masquerade 增强，版本号与 xboard-u v2.2.0 对齐。

- 修复 Sing-box HY2 未写入正值上下行带宽；服务端通信字段及独立模式带宽保持服务端视角，不重复交换面板转换后的方向。
- 接收并应用面板两内核 Masquerade 配置，覆盖单节点、机器模式 REST / WebSocket；独立模式也可在 standalone.node.hy2_settings 配置。
- 新标记下空带宽要求 BBR，正值允许 Brutal 协商；没有新标记的旧面板保留原协商默认行为。QUIC 窗口、超时和 MTU 等保持内核默认。
- 修正 Xray HY2 十进制带宽、BBR 的 auto 握手响应、单方向未设置限制时的协商及 Salamander / Gecko 映射。
- 修复 Sing-box 字符串伪装指定状态码后丢失响应头的问题；新增字段校验、深拷贝和热重载验证。

## 升级与兼容

```sh
xbctl upgrade
```

建议先更新节点端，再更新面板到 v2.2.0。没有新增必填配置；旧面板 / 原版 Xboard 不带新标记时不会主动强制 BBR，仍使用既有通信接口与认证方式。本次验证了旧协议配置路径，未单独部署原版面板完成全栈回归。

**请核对原 HY2 正值带宽：此前未应用的限制现在会生效。** 面板带宽方向修正需同时升级面板，独立配置的 up_mbps/down_mbps 始终是服务端上传 / 下载。Hysteria 1 行为不变。

内核版本保持 Sing-box 1.14.4、Xray-core 26.10.31，包含项目兼容补丁。配置见 [HY2 配置说明](https://github.com/Toto0912/xboard-node-u/blob/v2.2.0/docs/HYSTERIA2.md)。

## 验证

本地隔离环境完成全量 race 回归、生产标签编译、两内核共 24 组实际 HTTP/3 伪装 / 认证 / HY2 代理场景，以及编译后独立模式程序验证；覆盖 BBR、Brutal、单方向带宽、客户端 BBR、两种混淆、旧配置、重复认证和热重载。两份内核补丁在干净源码上重新应用并匹配测试源码。未开展公网吞吐或长期稳定性压测。
