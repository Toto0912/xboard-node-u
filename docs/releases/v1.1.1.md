# xboard-node-u v1.1.1

独立模式的 Xray 单目标回落与面板行为统一，项目版本与 **xboard-u v1.1.1** 对齐。内核仍为 sing-box 1.14.4、Xray-core 26.10.31，包含原有兼容补丁和安全修复。

- 在主配置文件的独立节点 `standalone:` → `node:` 内添加 `xray_fallback: "127.0.0.1:8443"`，与 `tls_settings:` 同级。
- Xray + Reality：有效回落目标覆盖 `tls_settings.dest`，保留 SNI、私钥、Short ID 和 Flow。目标应支持 TLS 1.3，证书匹配原 SNI。
- Xray + 普通 TLS：连接明文后端，使用 HTTP/1.1 普通回落。仅适用于 VLESS / Trojan、TCP/RAW；普通 TLS 回落不能与 VLESS 额外加密组合使用。
- sing-box 忽略新字段；留空、无效目标和不适用的协议组合保持原行为。
- 保留 `fallbacks` 多规则列表，仍仅限普通 TLS。Reality 旧配置中的 `fallbacks` 列表须删除，改用单目标 `xray_fallback`；有效单目标不能与多规则列表同时配置。
- 面板机器模式、单节点模式继续使用面板 Fallback 输入框，节点端无需重复填写。

完整说明见[独立运行指南](https://github.com/Toto0912/xboard-node-u/blob/v1.1.1/docs/STANDALONE.md)和 [Xray Reality 配置示例](https://github.com/Toto0912/xboard-node-u/blob/v1.1.1/examples/standalone-xray-reality-fallback.yml.example)。

本地隔离验证通过：14 个测试包、369 个测试项的完整 race 回归，VLESS / Trojan 的 TLS / Reality 网站回落与合法代理连接，以及编译后程序的 7 组启动检查（含新示例、多实例、sing-box 忽略、无效及空配置兼容）。测试缓存、程序和运行配置均位于源码目录外。

## 更新

systemd 和 Alpine/OpenRC 均执行：

```sh
xbctl upgrade
```

升级保留原配置与凭据。新增独立模式回落字段需更新到 v1.1.1 后再使用；未使用新字段的配置无需修改。
