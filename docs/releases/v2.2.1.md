# xboard-node-u v2.2.1

同步 Xray-core 官方最新正式版 **26.11.9**，保留项目兼容补丁。Sing-box 保持 **1.14.4**。

## 更新内容

- 固定 Xray 官方提交 `676eaf66f8f05d4d558ee7a74b4736623d3feeb9`，更新对应 Go 模块版本。
- 迁移调度限速、用户热更新、流量统计、在线设备、MUX 和 HY2 的既有兼容补丁。
- 同步新版要求的 uTLS、Reality、gRPC 等依赖及校验记录；更新源码准备脚本、第三方来源和配置文档。

## 升级与兼容

```sh
xbctl upgrade
```

兼容配套面板 xboard-u v2.2.0；此次只更新节点端，无需同步升级面板。机器模式、面板单节点模式和无面板独立运行沿用原配置与通信接口。

原版 Xboard / 旧版面板不带可选扩展字段时，仍保留既有默认处理；本地验证使用模拟面板，没有另行部署原版面板做完整生产回归。

从源码构建时，请在干净构建目录重新运行 `make prepare`。准备脚本会拒绝覆盖不同提交或包含手工改动的内核目录；请先保留自己的内核改动。

## 已完成的本地验证

- 全量生产标签与 race 回归：15 个含测试包，248 个顶层测试、464 个含子用例结果通过。
- 10 组 Xray 真实协议、双内核 24 组 HY2 场景，以及 TLS / Reality 原生回落、XHTTP、用户更新、流量统计和并发监听生命周期测试通过。
- Linux amd64 / arm64 的节点端与 xbctl 均编译成功；实际程序确认 Xray 26.11.9、Sing-box 1.14.4-xboard.1。
- 实际二进制的独立、单节点、机器模式均完成代理回环、健康检查与退出释放端口；两种面板模式成功上报双向流量。
- 干净内核源码重新应用补丁、准备脚本重复运行，以及补丁相关四个上游模块的 race 测试通过。

测试均在本地隔离环境完成，未连接 VPS；没有进行公网吞吐或长期稳定性压测。本次发布沿用上述验证结果，不额外追加本地测试。

参考：[Xray 官方发布记录](https://github.com/XTLS/Xray-core/releases/tag/v26.11.9)、[节点端功能说明](https://github.com/Toto0912/xboard-node-u/blob/v2.2.1/docs/二次开发功能说明.md)。
