# xboard-node-u v2.3.0

新增 HY2 端口跳跃自动转发，配套 xboard-u v2.3.0，兼容原版及旧版 Xboard。

## 新增功能

- 接收可选 hy2_settings.port_range，范围首端口继续使用整数 server_port；Sing-box / Xray 共用一个 HY2 入站与用户／流量统计。
- 支持机器模式、面板单节点模式及无面板独立模式。
- Linux 优先使用可用 nftables，兼容 iptables / ip6tables，按监听地址处理 IPv4 / IPv6。
- 新增实例所有权、并发协调、地址／范围冲突检查、幂等更新、失败回滚、残留恢复和生命周期清理。
- 停止、删除节点、改回单端口和卸载时只清理所属自动规则；更新 systemd / OpenRC 管理路径，保留其他节点与管理员规则。
- 机器子节点失败可重试，停止完成前保留句柄，防止新旧实例交叉清理。

## 升级与兼容

~~~sh
xbctl upgrade
~~~

启用自动范围前，确认系统存在可用 nftables 或 iptables / ip6tables、具备相应网络管理权限，并放行对应公网 UDP 范围。新装安装器提供相关依赖；受限 LXC 可继续使用服务端单端口及宿主机手动转发。

旧版或原版面板未下发范围时保持单端口行为，不接管现有手动规则。跳跃间隔由客户端执行，不会让服务端定时更换入站端口。范围变更可能影响已有连接，强制结束或断电由服务管理器／下次启动补充恢复。

内核保持 Sing-box 1.14.4、Xray-core 26.11.9；既有带宽方向、BBR / Brutal、证书、Masquerade、DNS、自定义配置与流量统计继续沿用。

## 验证

- 隔离 Go 完整测试和并发检测通过，真实 nftables 与 iptables 生命周期、回滚及活动实例保护通过。
- 两种服务端 × 两种原生客户端 × IPv4/IPv6 × 单端口／固定／随机，共 24 组流量测试通过，UDP 7086 发／7086 收；抓包确认实际跳跃。
- 真实本地面板单节点／机器模式 8 组接入，iptables 兜底双栈 4 组通信，以及机器冲突修正恢复均通过。
- Alpine / OpenRC 21 项安装管理检查，以及真实 HY2 服务崩溃恢复、停止、卸载和无关规则保留通过。
- 测试使用独立副本与临时容器，不包含公网、实际 LXC 或 iOS 客户端实机验证。
