# xboard-node-u v1.0.0

首个正式版，整合 sing-box 1.14.4 和 Xray-core 26.10.29，支持机器模式、单节点接入面板及无面板独立运行。

## 一行命令安装

在使用 systemd 的 Linux 上执行，按提示选择模式、内核并填写面板信息：

```bash
curl -fsSL https://github.com/Toto0912/xboard-node-u/releases/latest/download/install.sh | sudo bash -s -- --interactive
```

自动识别 amd64/arm64，下载安装两套内核内嵌的节点程序和管理工具，配置并启动服务。密钥输入隐藏。
机器模式使用机器令牌；单节点模式使用面板通信密钥。

已有安装可以执行 `sudo xbctl upgrade --version v1.0.0`。

## 主要内容

- 升级两套内核，保留节点同步、用户更新、限速、设备限制与流量统计。
- 修复内核配置重载、混合内核机器配置解析及认证表/会话状态并发问题。
- 新增交互安装向导；README 优先介绍 systemd 安装，源码构建移到后面。
- 提供固定上游提交、完整兼容补丁、重建脚本、配置示例和许可证文件。

## 下载

- Linux amd64：`xboard-node-linux-amd64` 和 `xbctl-linux-amd64`。
- Linux arm64：`xboard-node-linux-arm64` 和 `xbctl-linux-arm64`。
- `source-with-kernels.tar.gz`：包含已应用补丁的内核及传输依赖源码。
- `SHA256SUMS.txt`：附件校验值；`licenses.tar.gz`：第三方许可证。

交互安装流程通过本机 Ubuntu 管道与伪终端测试。
