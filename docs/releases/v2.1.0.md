# xboard-node-u v2.1.0

2026-11-07 同版本修复：Xray Reality 正确组合面板分开填写的伪装站点 `dest` 与端口 `server_port`，空目标回退到 SNI；已含端口的目标、SNI 和原生 fallback 保持原有含义。修复覆盖机器、单节点及独立模式，已通过配置解析、Reality 实际代理/回落及相关回归测试。已安装 v2.1.0 的用户可再次执行 `xbctl upgrade` 获取此次修复。

- 修复 Xray 并发准入和连接统计时的共享映射访问，停止实例时同步释放监听端口。
- 设备上报使用独立完整快照，持续在线按周期刷新，最后断开明确上报空快照，失败后继续使用最新状态重试。
- 修复机器模式复制空列表为 null、导致相同配置在 WebSocket 重连时误触发内核重启的问题。
- 删除无用的流量快照复制、旧设备哈希去重、失效缓冲及设备恢复代码，简化生命周期处理。

本地已通过全量 race 检测，完成 Xray 单节点、Xray 机器模式、Sing-box 单节点及独立 SS 的真实流量验证；面板 WS 重启后连接持续传输、设备状态恢复，全部断开后在线计数归零。Linux 构建与安装脚本检查通过。

配套面板发布为 xboard-u v2.1.0。三种部署模式无需新增配置，通信接口及认证方式保持不变；原版 Xboard 仍须提供既有握手与上报接口，本次未单独完成原版面板的完整回归。

嵌入内核仍为 Sing-box 1.14.4、Xray-core 26.10.31，包含现有 Xboard 兼容补丁。使用 `xbctl upgrade` 更新，更新后由原配置继续运行。
