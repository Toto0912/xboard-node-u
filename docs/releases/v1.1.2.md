# xboard-node-u v1.1.2

与 xboard-u v1.1.2 统一使用 Xray 原生协议层回落。内核仍为 sing-box 1.14.4、Xray-core 26.10.31。

- 独立模式使用 `standalone.node.fallbacks` 列表，支持 VLESS / Trojan TCP/RAW + TLS / Reality 的原生多规则回落，不增加单目标独立字段。
- 面板单目标转换为协议层回落，Reality 保留原 dest、SNI、密钥、Short ID 和 Flow，不再覆盖伪装目标。
- Reality 鉴权失败仍转发到原 HTTPS 目标；通过 Reality 握手后的代理协议失败才进入回落列表。VLESS 额外加密不能与协议层回落组合。
- 保持 sing-box 忽略面板字段及客户端订阅兼容，修复 Xray Reality 原目标端口读取。

升级前检查旧面板 Reality Fallback：它不再代表 HTTPS 伪装目标；面板和节点端需要一并升级到 v1.1.2。已有数据保留，不做自动端口替换或清空。完整位置及示例见 [独立运行指南](https://github.com/Toto0912/xboard-node-u/blob/v1.1.2/docs/STANDALONE.md)。

本地隔离验证通过：节点端 14 个测试包、373 个测试项的完整 race 回归；与面板及 MySQL 联调的 16 个面板节点和独立示例通过初始与 WebSocket 更新后共 62 项检查。覆盖两协议、两种安全性、两内核、机器/单节点、Reality 原目标保留及默认/路径/SNI/PROXY protocol 回落。

## 更新

systemd 和 Alpine/OpenRC 均执行：

```sh
xbctl upgrade
```

**面板应同步升级到 xboard-u v1.1.2。** 旧版依赖 Reality Fallback 覆盖目标站的配置需先核对，区分 HTTPS 伪装目标与明文协议回落后端；升级保留原配置和凭据，不自动替换端口。

发布附件包含 Linux amd64 / arm64 节点程序及相同版本 xbctl、两种安装器、完整内核源码与许可证、SHA256 校验清单。Docker 提供对应版本和 `latest`。
