# xboard-node-u v2.4.1

本版配套 Xboard-u v2.4.1，内置 sing-box 1.14.4 和 Xray-core 26.11.9。

## 主要变更

- **流量上报**支持批次持久化、失败重发和回执确认。配套面板按批次去重，避免响应丢失后同一批流量重复入账。速率统计支持默认和自定义采样间隔。
- **用户授权**在 WebSocket 重连后按面板名单对账。迟到的 REST 响应、机器模式合并推送及失败回滚均会校验用户凭据。零用户节点在收到有效名单后恢复服务。
- **机器模式**支持运行中的 sing-box 子节点在切换 XHTTP 时自动改用 Xray，仅替换受影响子节点。多个 Xray 子节点各自使用本实例的 DNS 和出站。
- **证书与限速**改进 ACME 续签重载、切换失败回滚和静态多节点证书目录迁移，修复 Xray VLESS TCP 上行限速。

## 升级

1. 先更新面板并完成数据库迁移。异步队列部署请确认新版 worker 消费 `traffic_batch` 队列，Laravel 调度器正常运行。
2. systemd 或 OpenRC 安装可以执行 `xbctl upgrade --version v2.4.1`。Docker 部署可拉取 `ghcr.io/toto0912/xboard-node-u:v2.4.1` 并按原配置重建节点容器。
3. 保留可写的流量批次目录及其持久卷。面板与节点自动协商协议，无需修改节点配置启用批次。要回退面板或迁移节点时，先确认离线节点也已补传，保留接收端、消费者和去重记录直到积压清空。

升级会重启被更新的节点，客户端需要重连。建议先升级一台节点，核对连接、速率和流量入账后再升级其余节点。
