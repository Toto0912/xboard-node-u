# xboard-node-u v1.1.3

支持面板下发原生自定义出站与路由，配合 xboard-u v1.1.3 使用。内核仍为 sing-box 1.14.4、Xray-core 26.10.31，包含原有 Xboard 兼容补丁。

- Sing-box 原生 type 出站无需套 protocol/settings；原生 detour、TLS、transport 等字段完整保留。
- Xray 原生出站保留 streamSettings、proxySettings、mux 等字段。
- 兼容旧面板格式；旧 proxy_tag 在 Sing-box 下转换为 detour。
- 检查错误内核格式、未知出站引用和依赖循环；未知原生参数交由实际内核解析，避免面板白名单限制新字段。
- REST 与嵌套 WebSocket 配置解码保留原生字段和空对象；自定义配置仅用于服务端。
- 不新增数据库迁移，不更改已嵌入的内核版本。

升级时保留已有数据库与配置。先更新节点端，再使用新的原生配置；已有旧格式不需要改写。

## 更新

现有 systemd 或 Alpine/OpenRC 部署执行：

```sh
xbctl upgrade
xbctl status
```

已有配置保留。先更新节点端，再在面板保存新的 Sing-box 原生出站。原生配置不做跨内核翻译；错误格式、未知标签与依赖循环会明确拒绝，完整参数仍须受实际内核版本支持。

配置说明：[自定义出站](https://github.com/Toto0912/xboard-node-u/blob/v1.1.3/docs-custom-outbounds.md)、[自定义路由](https://github.com/Toto0912/xboard-node-u/blob/v1.1.3/docs-custom-routes.md)。

本地隔离验证：节点14个测试包、400项测试/子测试及 race 检查通过。双内核、单节点/机器模式、原生/旧格式共8个真实面板节点，初始及自动更新后16次流量检查通过；REST 与 WebSocket 字段保留均有专项检查。
