# xboard-node-u v1.1.0

新增 Xray 回落功能，同时支持 **xboard-u v1.1.0** 面板下发和无面板独立配置。内核仍为 sing-box 1.14.4、Xray-core 26.10.31，包含原有 Xboard 兼容补丁及安全修复。

- 机器模式、面板单节点模式均支持可选 `xray_fallback`，覆盖 REST 拉取和 WebSocket 配置更新。
- Xray VLESS / Trojan TCP/RAW + TLS 使用普通明文回落，默认 HTTP/1.1。不能与 VLESS 额外加密同时使用。
- Xray + Reality 将面板回落地址作为 HTTPS 伪装目标，支持“Reality 偷自己”，保留原 SNI、密钥及 Short ID。目标需支持 TLS 1.3，证书匹配原 SNI。
- sing-box 忽略面板回落配置，保持正常代理；该字段单独变化不触发多余重载。旧面板、空值和无效输入保持原行为。
- 无面板模式新增 `standalone.node.fallbacks`，支持 VLESS / Trojan TCP + 普通 TLS 的默认、SNI、ALPN、HTTP 路径回落及 PROXY protocol；不兼容或无效的本地配置会明确报错。
- 整理 README，新增[二次开发功能说明](https://github.com/Toto0912/xboard-node-u/blob/v1.1.0/docs/二次开发功能说明.md)及 [TLS 回落完整示例](https://github.com/Toto0912/xboard-node-u/blob/v1.1.0/examples/standalone-vless-fallback.yml.example)。

开发阶段已通过 14 个有测试包的完整 race 回归、TLS / Reality 网站回落和合法代理连接检查，以及两套内核、两种接入模式共 16 个本地节点的实际联调。保留原有独立模式回落测试。

## 更新

systemd 和 Alpine/OpenRC 均使用：

```sh
xbctl upgrade
```

建议先更新节点端，再升级 xboard-u 面板到 v1.1.0 或更新版本。已有配置和凭据会保留；面板回落在面板中配置，无需在节点端 `config.yml` 重复填写。

发布附件包含 Linux amd64 / arm64 节点程序、相同版本的 xbctl、systemd / Alpine 安装器、含内核源码的源码包、许可证及 SHA256 校验清单。Docker 同步提供版本标签和 `latest`。
