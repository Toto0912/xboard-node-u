# xboard-node-u v1.0.2

同步 **Xray-core v26.10.31 紧急安全更新**，默认关闭 Xray TCP 监听的 MPTCP，并为节点自身的健康检查监听显式关闭 MPTCP。sing-box 保持 1.14.4-xboard.1。

[Xray 官方公告](https://github.com/XTLS/Xray-core/releases/tag/v26.10.31)说明该措施用于减少相关 Linux TCP 内核漏洞的攻击面。**更新节点端不等于修复 Linux 内核，服务器仍应更新系统内核。** 用户自定义原生配置显式设置 `sockopt.tcpMptcp: true` 的行为仍保留。

## 已安装用户升级

systemd 系统：

```sh
sudo xbctl upgrade
```

Alpine / OpenRC，以 root 执行：

```sh
xbctl upgrade
```

管理工具自动选择安装方式，保留现有配置并更新节点与 xbctl。升级会重启服务，现有连接可能短暂中断。完成后检查：

```sh
xboard-node -v
xbctl status
```

非 root 的 systemd 用户在 `xbctl status` 前添加 `sudo`。内核版本应显示 **Xray 26.10.31**。

## 验证范围

发布前已在独立本地工作区完成全项目 Linux race、Xray 兼容补丁 race、两套内核协议回归、机器/单节点/无面板模式的真实回环代理请求及 OpenRC 21 项集成检查。

旧版与新版的 socket 系统调用对照确认：在同样环境及 `GODEBUG=multipathtcp=2` 下，新版不再尝试创建 MPTCP socket。arm64 完成交叉编译及模拟容器启动检查，完整部署与代理检查在 amd64 执行。发布流水线会另行执行完整 race、双架构构建及 Alpine 集成检查。

本次未连接或升级用户 VPS，未新增公网、长时间压力或 REALITY/Vision 端到端测试。
